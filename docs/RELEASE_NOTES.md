Aster 1.0 introduces **Flow**, a frameless command rail that works over gameplay and menu scenery. Dark charcoal, muted orange, clean typography, and settings that unfold inline give it a distinct interface.

Includes Auto Sprint, Fullbright, hold-to-zoom, Coordinates, Performance, and Keystrokes. Search, category filters, keyboard navigation, per-profile toggle keys, and named profile snapshots are built in.

**Install:** use Minecraft **26.3**, Fabric Loader **0.19.5+**, matching Fabric API **0.162.0+26.3**, and Java **25**. Put `aster-client-1.0.0.jar` and Fabric API in your profile's `mods` folder. Open with **Right Shift** or the title-screen entry; hold **C** to zoom.

Settings save locally and automatically. Existing development settings remain compatible. Corrupt settings are backed up; newer formats are protected from overwriting.

Downloads include the installable JAR, a documentation bundle, developer sources, and SHA-256 checksums. The bundle contains no Minecraft installation or Fabric API. See the installation guide and README for controls, limitations, and troubleshooting.

English UI; Minecraft 26.3 only. Module use remains subject to your server's rules. Aster is an independent MIT-licensed project.
